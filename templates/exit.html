Exit Tracking — Security Only
When a visitor exits, the currently logged-in security guard is recorded as the Exit Security.
Example:
Visitor enters while Duryodhan is on duty.
Later, Duryodhan's duty ends and Sakuni starts duty.
If Sakuni records the exit, the history will show:
Entry Security: Duryodhan
Exit Security: Sakuni
Only Security can mark the exit. Residents cannot mark a visitor exit. The original entry information is not overwritten.
