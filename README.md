# Ashtavinayak City Security Management System

## Project Overview

Ashtavinayak City Security Management System is a web-based security
management application developed as an academic Software Engineering
project for managing visitor registration, resident approval, visitor
entry, visitor exit and visitor history in a residential society
environment.

## Problem Statement

Traditional visitor management methods based on manual registers can
make it difficult to maintain accurate visitor records, obtain resident
approval and track visitor entry and exit information.

This project provides a digital solution for security personnel and
residents.

## Key Features

- Security authentication
- Visitor registration
- Visitor information validation
- Resident and flat selection
- Telegram-based approval request
- Approve / Disapprove visitor requests
- Visitor entry tracking
- Visitor exit tracking
- Security dashboard
- Visitor history
- Resident management
- Database management

## Technology Stack

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Telegram Bot API

## System Workflow

Security Login
        ↓
Visitor Registration
        ↓
Visitor Validation
        ↓
Resident Selection
        ↓
Telegram Approval Request
        ↓
Approve / Disapprove
        ↓
Visitor Entry
        ↓

        ↓
